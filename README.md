## 🧭 Overview

**SatExpert Tactical SatCom Intelligence (TSI) v6** is an enterprise-grade operational console for VSAT engineers, SIGINT field operators, and aerospace defense teams. It unifies high-precision orbital telemetry calculation, electronic warfare countermeasures, post-quantum cryptographic security, and autonomous AI defense into a high-performance, real-time command interface.

Designed for high-stress operational environments, TSI v6 features:
- **Zero-Latency Telemetry Streaming**: High-throughput updates across LEO, MEO, and GEO constellations.
- **Autonomous Threat Mitigation**: Active AI Decision Matrix that correlates telemetry trend derivatives with hostile space-based infrared reconnaissance pass windows.
- **Quantum-Safe Communications**: Entanglement-based Quantum Key Distribution (QKD) simulation with visual Bell-state verification and BB84/E91 protocol analysis.
- **Dynamic Thermal Decoys**: Real-time BUC temperature spoofing to deceive enemy infrared space and drone recon assets.

## ⚡ Key Tactical Systems

### 1. Sentinel AI Control & AI Decision Matrix
The **Sentinel AI Control** module operates as an autonomous threat monitoring and decision-support core:
- **Telemetry Trend Derivative Engine**: Continuously tracks rolling telemetry history ($\Delta T / \Delta t$ of BUC temperature, SNR drift rates, RX power variance, and packet loss).
- **Hostile ISR Dwell Window Predictor**: Calculates pass windows for adversary surveillance satellites (e.g., *COSMOS-2558*, *USA-326*) in mid-wave (MWIR) and long-wave (LWIR) infrared spectra.
- **Optimal Duration Recommender**: Computes an optimal duration (10s–60s) for **Heat Signature Spoofs** by balancing deceptive thermal bloom against amplifier junction limits ($85^\circ\text{C}$).
- **Tactical Spoof Profiles**:
  - *Sprint Pulse (15s)*: Rapid flare burst with minimal hardware strain for fast LEO flybys.
  - *Tactical Mask (30s)*: Standard military counter-reconnaissance envelope.
  - *Extended Spoof (45s)*: Sustained deceptive bloom for active EW and dual-satellite stare.
  - *Constellation Break (60s)*: Maximum flare burn for multi-satellite cluster handoffs.
- **Operator Trigger**: In-flight duration adjustment with instant deployment and emergency abort overrides.

### 2. Quantum Intelligence Hub & Real-Time QKD
- **Rotating Quantum Key Visualization**: Interactive canvas-based simulation of entangled photon pair ($\vert \Phi^+ \rangle$) distribution between orbital transmitters and ground stations.
- **Polarization Angle Diagnostics**: Simulates measurement basis alignment ($0^\circ, 45^\circ, 90^\circ, 135^\circ$), quantum bit error rate (QBER), and Bell inequality ($S \le 2\sqrt{2}$) verification.
- **Active Eavesdropper Injection**: Live Eve intercept-resend attack testing with real-time error rate escalation and key abort mechanics.
- **Exportable Cryptographic Certificates**: Instant generation of authenticated quantum key material.

### 3. Tactical HUD & Thermal Decoy Subsystem
- **Heads-Up Display (HUD)**: Dual-card orbital telemetry layout displaying Azimuth, Elevation, Polarization Skew, Slant Range, SNR, and RX Power.
- **BUC Temperature Override**: When the **Thermal Decoy** is engaged, telemetry dynamically transitions into a high-temperature flare bloom ($190^\circ\text{C}+$) with pseudo-random thermal flutter.
- **30-Second Countdown Overlay**: Visual and auditory countdown indicators with real-time status logging to mission event logs and Firestore audit trails.

### 4. Constellation Tracking & Look Angles Engine
- Real-time SGP4/orbital coordinate transformations calculated to sub-millimeter precision.
- Real-time calculation of look angles (Azimuth, Elevation, Polarization Tilt) relative to ground coordinates.
- Multi-band support: C-band, Ku-band, Ka-band, and X-band link budget calculations.

### 5. Electronic Warfare & Jamming Countermeasures
- Wideband and narrowband RF jamming synthesis.
- Zero-Point Energy (ZPE) noise-filtering emulation.
- Automated spectrum sniffing and waterfall display representation.

### 6. Post-Quantum Cryptography & Zero-Day Forge
- Implementation of NIST PQC standards: **ML-KEM (Kyber-1024)** and **ML-DSA (Dilithium-5)**.
- Automated exploit generation laboratory and audit suite for satellite firmware and ground-station software.

## 🚀 Quick Start Guide

### Prerequisites
- **Node.js**: `v20.12.0` or higher
- **npm** (`v10+`) or **bun** (`v1.1+`)
- Modern web browser with Web Audio and HTML5 Canvas support (Chrome, Firefox, Safari, Edge)

### Installation
Clone the repository and install all project dependencies:

```bash
# Clone the repository
git clone https://github.com/your-org/satexpert-tsi.git

# Navigate to project directory
cd satexpert-tsi

# Install dependencies
npm install
```

### Development Mode
Launch the local tactical development server with hot-reloading:

```bash
npm run dev
```

Open your browser at `http://localhost:3000` to access the console.

### Production Build
Compile and bundle the production client and Node.js server:

```bash
# Verify TypeScript typing
npm run lint

# Build production assets
npm run build

# Launch the production service
npm start
```

## ⚙️ Environment Configuration & GitHub Secret Hardening

To ensure that sensitive API keys and credentials are never exposed in public repositories:

1. **GitHub Protection via `.gitignore`**:
   - `firebase-applet-config.json` and `.env*` files are strictly added to `.gitignore`.
   - A sanitized template `firebase-applet-config.example.json` is provided for public reference.

2. **Environment Variables**:
   Create a `.env` file in the root directory following `.env.example`:

```env
# Server Port (Default: 3000)
PORT=3000

# Server-Side Google Gemini AI Integration (Never exposed to browser)
GEMINI_API_KEY=your_gemini_api_key_here

# Hardened Firebase Configuration (Vite client overrides)
VITE_FIREBASE_API_KEY=your_firebase_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=your_project_id
VITE_FIREBASE_DATABASE_ID=ai-studio-f55368ed-a497-4968-b73a-50421b2c02b7
VITE_FIREBASE_STORAGE_BUCKET=your_project.firebasestorage.app
VITE_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
VITE_FIREBASE_APP_ID=your_app_id
```

## 🛰️ Heat Signature Spoofing Protocol

```
[HOSTILE ISR PASS DETECTED]
             │
             ▼
  ┌───────────────────────┐
  │   Telemetry Buffer    │ ───►  Rolling ΔT/Δt & SNR Drift
  └───────────────────────┘
             │
             ▼
  ┌───────────────────────┐
  │   AI Decision Matrix  │ ───►  Calculates Optimal Spoof Window (10-60s)
  └───────────────────────┘
             │
             ▼
  ┌───────────────────────┐
  │   Operator Trigger    │ ───►  Manual override or 1-click execution
  └───────────────────────┘
             │
             ▼
  ┌───────────────────────┐
  │  BUC Telemetry Spoof  │ ───►  Synthetic Thermal Flare (190°C+)
  └───────────────────────┘

```

1. **Detection**: Sentinel AI detects an orbital reconnaissance pass by adversary infrared surveillance sensors.
2. **Analysis**: AI Decision Matrix samples the last 15 telemetry ticks, factoring in ambient temperature, weather rain fade, and jamming power.
3. **Recommendation**: Suggests an optimal duration (e.g., $32\text{s}$) that exceeds the sensor dwell window while protecting BUC hardware integrity.
4. **Spoof Trigger**: Operator triggers the decoy. BUC telemetry is overridden with an oscillating thermal bloom signature.
5. **Normalization**: Upon timer expiration, telemetry returns to nominal baseline and an authenticated audit event is committed to mission logs.
