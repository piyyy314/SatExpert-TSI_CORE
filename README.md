# SatExpert Tactical SatCom Intelligence (TSI) v6

The ultimate professional toolkit for VSAT/SIGINT operations. v6 features an Integrated AI Sentinel, Quantum Intelligence Hub, and Advanced Purple Team Arsenal.

View your app in AI Studio: https://ai.studio/apps/f55368ed-a497-4968-b73a-50421b2c02b7

## Features

- **Integrated AI Sentinel**: Powered by the Gemini API for advanced situational awareness.
- **Quantum Intelligence Hub**: Post-quantum cryptography integrations.
- **Advanced Purple Team Arsenal**: Comprehensive tools for VSAT operations.
- **Permissions**: Requires Geolocation, Microphone, Camera, and USB access.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   ```bash
   npm install
   ```
2. Set the `GEMINI_API_KEY` in `.env.local` to your Gemini API key.
3. Run the app:
   ```bash
   npm run dev
   ```
