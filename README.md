## 🔑 Firebase Environment Configuration

Find your Firebase credentials in the **Firebase Console** ([console.firebase.google.com](https://console.firebase.google.com)):
1. Open your project.
2. Click the **Gear icon (Project Settings)** in the top left.
3. Under the **General** tab, scroll down to **Your apps** and select your Web App (`</>`).
4. Copy the `firebaseConfig` keys into your `.env` file:
   - `VITE_FIREBASE_API_KEY` (`apiKey`)
   - `VITE_FIREBASE_AUTH_DOMAIN` (`authDomain`)
   - `VITE_FIREBASE_PROJECT_ID` (`projectId`)
   - `VITE_FIREBASE_DATABASE_ID` (Firestore database ID)
   - `VITE_FIREBASE_STORAGE_BUCKET` (`storageBucket`)
   - `VITE_FIREBASE_MESSAGING_SENDER_ID` (`messagingSenderId`)
   - `VITE_FIREBASE_APP_ID` (`appId`)
   - `VITE_FIREBASE_MEASUREMENT_ID` (`measurementId`)

## 🚀 Quick Start Guide

### Prerequisites
- **Node.js**: `>= 22.12.0`
- **npm**: `>= 10.0.0`

### Installation
```bash
git clone https://github.com/piyyy314/satexpert-tsi.git
cd satexpert-tsi
npm install
```

### Development Mode
```bash
npm run dev
```

### Production Build
```bash
npm run build
```

## 📦 PyPI Automatic Publishing & Distribution

This project includes a dedicated GitHub Actions workflow (`.github/workflows/publish-pypi.yml`) and `pyproject.toml` configuration to automatically build and publish distribution archives (`.whl` and `.tar.gz`) to **PyPI (pypi.org)** upon creating a GitHub Release.

## 🔒 Security Policy & Secret Hardening

All secrets (Firebase keys, Gemini API tokens) are strictly isolated to server-side proxy routes and runtime environment variables (`.env`). No API keys or service account secrets are hardcoded in the source code or committed to GitHub.

For vulnerability reports, please review [`SECURITY.md`](./SECURITY.md).
